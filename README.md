# DART 미니 데이터북

회사명을 넣으면 OpenDART에서 최근 5개년 연간 재무제표를 받아, 실사(FDD) 데이터북의 뼈대를
화면과 **수식이 살아있는 엑셀**로 만들어 주는 개인 학습용 도구입니다. 공개 데이터만 사용합니다.

## 실행

1. `.env` 파일에 OpenDART 인증키를 넣습니다.
   ```
   DART_API_KEY=발급받은키
   ```
2. 앱을 띄웁니다.
   ```bash
   .venv.nosync/bin/streamlit run app.py
   ```

### 맥 앱으로 실행

```bash
.venv.nosync/bin/python tools/build_mac_app.py
```

`dist/DART 데이터북.app`이 만들어집니다. 더블클릭하면 브라우저 없이 전용 창으로 열리고, 창을 닫으면 서버도 함께 끝납니다.
응용 프로그램 폴더나 Dock으로 옮겨도 됩니다.

이 앱은 파이썬을 통째로 담은 것이 아니라 **이 프로젝트 폴더와 가상환경을 실행하는 실행기**입니다.
프로젝트 폴더를 옮기거나 이름을 바꾸면 위 명령으로 앱을 다시 만들어야 하고, 다른 맥에 앱 파일만 복사해서는 실행되지 않습니다.
문제가 생기면 `~/Library/Logs/DART Databook/server.log`를 확인하세요.

가상환경을 새로 만들 때:

```bash
python3 -m venv .venv.nosync && .venv.nosync/bin/pip install -r requirements.txt
```

(`.nosync`는 iCloud가 가상환경 폴더를 동기화하지 않게 하는 이름입니다.)

## 화면

- **기업 찾기**: 코스피·코스닥 시가총액 순위(로고 포함)에서 회사를 고르거나 이름·종목코드로 검색합니다.
  행을 누르면 오른쪽에 기업 개황과 "무엇을 하는 회사인가"(최근 사업보고서의 *사업의 개요*)가 나옵니다.
- **데이터북**: 고른 회사의 5개년 요약, 재무제표, 순운전자본, 순차입금, 분류 확인, 기업 소개 탭과 엑셀 내려받기.

- **엑셀 학습** (화면 맨 아래 "엑셀 학습하기" 버튼): 
  - *기능 학습*: 단축키(Windows·Mac), 함수(매일 쓰는 기본 / 가끔 쓰는 응용 / 함께 알아두기), 매크로(VBA).
    함수와 단축키의 뼈대는 「회계법인 실무에서 매일 쓰는 기본엑셀」 문서를 따릅니다.
  - *실전 예제에 적용하기*: 회사와 익히고 싶은 기능을 고르면, 그 회사 재무제표가 든 **과제 파일**과
    정답 수식·해설이 든 **정답 파일**을 만들어 줍니다. 매크로 과제를 고르면 정답 코드(.txt)도 함께 나옵니다.
    과제는 AI가 아니라 `databook/practice.py`의 기능별 생성 규칙으로 만들어지므로 비용이 들지 않습니다.

데이터 출처

| 내용 | 출처 |
|---|---|
| 재무제표, 기업 개황, 사업의 개요 | 금융감독원 OpenDART (공식 API, 인증키 필요) |
| 시가총액 순위, 현재가, 로고 이미지 | 네이버 증권 모바일 API (비공식, 10분 캐시 + 새로고침 버튼) |

네이버 쪽은 공식 API가 아니라 예고 없이 바뀌거나 막힐 수 있습니다. 그 경우에도 검색과 데이터북은 DART만으로 동작합니다.
색상·글꼴은 `.streamlit/config.toml`과 `app.py` 맨 위의 색상 상수에서 바꿉니다.

## 엑셀 구성

| 시트 | 내용 |
|---|---|
| 요약 | 매출·EBITDA·NWC·순차입금 5개년과 검증 결과 |
| BS / IS / CF | DART 원본 값(파란 글씨). B열에 분류·태그 |
| NWC | 순운전자본, 매출 대비 비율, 회전일수 |
| 순차입금 | 차입금 − 현금성자산, 유사차입금 |
| EBITDA | 영업이익 + 감가상각비, QoE 조정 연습 칸 |
| 비율 | 성장성·수익성·안정성·현금흐름 |
| 체크 | 자산 = 부채 + 자본, 계정 합계 = 총계 |

분석 시트는 원본 시트 **B열을 `SUMIFS`로 집계**합니다. BS 시트에서 어떤 계정의 분류를 바꾸면
NWC·순차입금이 따라 바뀌므로, "이 계정은 운전자본인가 차입금인가"를 직접 판단해 볼 수 있습니다.

- 파란 글씨 = 원본 값, 검은 글씨 = 수식, 노란 칸 = 직접 입력
- 셀 값은 원 단위이고 표시형식으로만 백만원을 보여줍니다. 노란 칸에는 원 단위로 입력하세요.

## 공부 포인트

- **미분류 계정**(주황색): '기타유동금융자산'처럼 이름만으로는 성격을 알 수 없는 계정입니다. 주석을 읽고 정해 보세요.
- **유사차입금**: 퇴직급여부채, 미지급법인세, 미지급배당금 등은 자동으로 넣지 않았습니다. 직접 분류해 순차입금이 어떻게 달라지는지 보세요.
- **QoE 조정**: EBITDA 시트의 노란 칸에 일회성·비경상 항목을 넣어 조정 후 EBITDA를 만들어 보세요.

## 한계

- 사업보고서를 제출하는 회사만 조회됩니다(주로 상장사). 비상장 외감법인은 이 API로 재무제표가 나오지 않습니다.
- 금융업(은행·보험·증권)은 계정 구조가 달라 지원하지 않습니다.
- 감가상각비가 현금흐름표에 따로 나오지 않는 회사는 EBITDA 시트 노란 칸에 주석 금액을 직접 넣어야 합니다.
- 과거 연도는 그 해 사업보고서에 처음 보고된 금액이라, 이후 재작성된 금액과 다를 수 있습니다.
- 자동 분류는 계정명 기준의 출발점입니다. 그대로 믿지 말고 확인하세요.
